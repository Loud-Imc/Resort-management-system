📱 Remote App Update Integration Guide

Target: Flutter Mobile Developer  •  Status: Live on Dev Backend

Core Principle: The backend owns the update policy rules; Flutter enforces them. No minimum versions are hard-coded in Flutter. Admins control rollout and enforcement remotely from the admin dashboard.

1. Public API Endpoint (No Authentication Required)

Call this endpoint during Flutter app startup and when returning to foreground:

GET /api/v1/app/update-config?platform=android&version=2.4.0

(Alias: GET /api/app/update-config)

Request Parameters

Parameter Type Required Description Example
platform string Yes android or ios (lowercase) android
version string Yes Installed app version from package_info_plus 2.4.0
appId string No Flavor / Bundle identifier com.oreedu.app

2. JSON Response Contract

{
  "platform": "android",
  "currentVersion": "2.4.0",
  "minimumSupportedVersion": "2.5.0",
  "latestVersion": "2.6.0",
  "updateType": "force",
  "updateRequired": true,
  "title": "Update Required",
  "message": "A new version of the app is required to continue using the service.",
  "storeUrl": "https://play.google.com/store/apps/details?id=com.oreedu.app",
  "policyVersion": 2,
  "publishedAt": "2026-09-14T05:15:00.000Z"
}

Understanding updateType Actions:

updateType updateRequired Flutter Client Action
force true Block user. Show non-dismissible screen. Tapping "Update Now" launches storeUrl.
optional false Show optional update popup with "Update" and "Later" buttons. Allow entry.
none false App is supported and up to date. Open login/home directly.

3. Flutter Implementation Rules

  1. Root Startup Gate: Check the endpoint before showing login or loading authenticated data.
  2. Disable Back Button on Force Update: Use PopScope(canPop: false) so Android users cannot press back to bypass the screen.
  3. App Resume Re-check: Use WidgetsBindingObserver to detect AppLifecycleState.resumed. When the user returns from the Play Store/App Store after updating, re-evaluate automatically.
  4. Fail-Open Fallback: If the endpoint times out (set 5s timeout) or network is offline, do not lock users out—fallback to cached policy or allow normal entry.
  5. Store Redirection: Launch storeUrl using url_launcher with LaunchMode.externalApplication.

4. Dart Model Snippet

enum UpdateType { none, optional, force }

class AppUpdateConfig {
  final String platform;
  final String currentVersion;
  final String minimumSupportedVersion;
  final String latestVersion;
  final UpdateType updateType;
  final bool updateRequired;
  final String title;
  final String message;
  final String storeUrl;
  final int policyVersion;

  AppUpdateConfig({
    required this.platform,
    required this.currentVersion,
    required this.minimumSupportedVersion,
    required this.latestVersion,
    required this.updateType,
    required this.updateRequired,
    required this.title,
    required this.message,
    required this.storeUrl,
    required this.policyVersion,
  });

  factory AppUpdateConfig.fromJson(Map<String, dynamic> json) {
    UpdateType parseType(String? type) {
      switch (type?.toLowerCase()) {
        case 'force': return UpdateType.force;
        case 'optional': return UpdateType.optional;
        default: return UpdateType.none;
      }
    }

    return AppUpdateConfig(
      platform: json['platform'] ?? '',
      currentVersion: json['currentVersion'] ?? '',
      minimumSupportedVersion: json['minimumSupportedVersion'] ?? '1.0.0',
      latestVersion: json['latestVersion'] ?? '1.0.0',
      updateType: parseType(json['updateType']),
      updateRequired: json['updateRequired'] ?? false,
      title: json['title'] ?? 'Update Required',
      message: json['message'] ?? 'A new version of the app is available.',
      storeUrl: json['storeUrl'] ?? '',
      policyVersion: json['policyVersion'] ?? 1,
    );
  }
}

5. Admin Portal Details

The operations team manages policies at /mobile-updates in the Admin Portal:

  • Independent controls for Android & iOS
  • Minimum version, latest version, store URLs, and custom messaging
  • Interactive live version tester and phone screen mockup simulator
  • Safety confirmation prompt before enabling Force Updates
